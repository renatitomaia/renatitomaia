### 📂 Projetos em Destaque

#### 🏗️ [Assistente Inteligente Text-to-SQL para Gestão de Obras](https://github.com/renatitomaia/projeto-02-text-to-sql)
> **Aplicação Web em Streamlit que traduz perguntas em linguagem natural em consultas SQL e dashboards executivos para acompanhamento orçamentário.**

Plataforma integrada à API do Google Gemini (Gemini 3.6 Flash) para permitir que gestores consultem a base de dados dimensional (*Star Schema*) da obra sem necessidade de conhecimentos técnicos em SQL. Inclui validação de schema, síntese executiva em português gerada pela IA, gráficos dinâmicos com Plotly e exportação de relatórios em CSV e Excel.
- **Tech Stack:** `Python` `Streamlit` `SQLite` `SQLAlchemy` `Google GenAI` `Pandas` `Plotly`

---

#### 📊 [Dashboard de Performance & Custos de Engenharia (Power BI)](https://github.com/renatitomaia/Performance-de-Obra)
> **Modelagem dimensional e relatórios interativos para acompanhamento do avanço físico e financeiro de projetos.**

Desenvolvimento de modelo de dados focado na curva S de avanço físico vs. financeiro, medições de contratos e desvios orçamentários por categoria de serviço. Integração de fontes para acompanhamento de KPIs estratégicos de diretoria.
- **Tech Stack:** `Power BI` `DAX` `Modelagem Dimensional (Star Schema)` `ETL`

---

#### ⚙️ Pipeline ETL Automatizado + API REST (FastAPI) *(Em Desenvolvimento)*
> **Ingestão, tratamento e consolidação de dados heterogêneos de relatórios diários de obra.**
